# 设计规格：旅行四辑「精选图文」整书 PDF

日期：2026-07-31  
范围：《我的人生旅行》第一～四辑整书 PDF（书架「分享／PDF」）  
非范围：《雲心文集》整书 PDF、文章页单篇 PDF（本次不改）

## 背景

当前整书 PDF 为文字版：封面仅为文字标题页，`blocksToParagraphs` 跳过全部图片。用户需要更接近实体书的分享文件：有封面图、有代表性内文照片，同时避免手机端一次渲染上千张图导致 OOM／超时。

## 目标

1. 旅行四辑整书 PDF 包含该辑书架封面图与正文精选配图。
2. PDF 内明确注明：完整配图请在手机打开 cloudscroll.net 在线阅读。
3. 仍在浏览器端用现有 iframe + 分段 html2pdf 完成，不新增后端。

## 页序结构

1. **封面页（全幅图）**  
   - 图源：`images/cover_v{N}.jpg`（N = 1…4，与书架一致）。  
   - 上叠暗角／半透明遮罩，文字：书名「我的人生旅行」、辑名、作者「林樺」、品牌「雲箋文舍」。  
   - 可选小字「精选图文版」；**不再**出现「文字版」。  
   - 封面可不显示页脚 URL。

2. **说明页**  
   固定文案（可微调标点，语义不变）：  
   > 本 PDF 为精选图文版，便于分享阅读。完整配图与排版请在手机打开 cloudscroll.net 在线阅读。

3. **目录**  
   维持文章标题列表；辑名可作为目录小标题。

4. **正文**  
   按文章顺序：篇题 → 段落与精选图交错 → 篇间自然分页（沿用分段 chunk）。

5. **页脚**  
   非封面页底部保留 `cloudscroll.net`。

## 选图规则

- 数据源：各篇 `book/{id}.json` 的 `blocks`（`type === 'image'`）。  
- 每篇按出现顺序最多取 **5** 张；不足则全收；无图则纯文字。  
- 导出渲染前将图片缩至最长边约 **900px**，JPEG 质量约 **0.82**（canvas 或等效方式），降低内存与 PDF 体积。  
- 交错策略：有图时，大致每隔若干段落后插入下一张图，避免全部堆在文末。  
- 单图加载失败：跳过该图，不中断全书。

## 正文版式

- 延续现有 PDF iframe 内衬线字体与色板（暖纸色背景、深墨字）。  
- 篇题较大；正文两端对齐、舒适行距。  
- 图片通栏，细边框或轻圆角；无强制图注（除非后续从 blocks 读到说明文字——本次不做）。  
- 带图 chunk 适当减少每段文字批次数，避免单次 html2canvas 节点过高。

## 技术要点

- 主要改动文件：`src/js/article-pdf.js`（及必要时极小的 `shelf.js` 进度文案）。  
- `loadTravelVolumeBook`：除段落外收集每篇 `imageSrcs`（路径相对站点，如 `book/images/...`）。  
- `buildBookChunks`：增加 `cover`（含 `coverSrc`）、`notice`；`article` chunk 可携带 `images` 或图文混合序列。  
- `buildBookChunkRoot`：渲染封面图、说明页、正文 `<img>`（需在 iframe 内等待 decode／onload 再截图）。  
- 《雲心文集》`loadYunxinBook` / `exportBook` 路径保持现状。  
- 进度文案示例：「正在生成精选图文 PDF…（含封面与照片，请稍候）」。

## 交互与错误处理

- 书架导出入口与分享／下载逻辑不变。  
- 文章 JSON 失败：该篇标题 +「本文暫未能載入」。  
- 微信内仍可能需先下载再转发；说明页已引导网站看全图。

## 验收标准

1. 第四辑导出：封面为 `cover_v4.jpg` 全幅风格；有说明页；至少一篇有图的文章出现配图；无「文字版」字样；含 cloudscroll.net 引导语。  
2. 第一～三辑同样使用对应 `cover_vN.jpg` 与选图规则。  
3. 第二辑能完整生成（允许较慢）；不出现空白 PDF／整页裁切错位（保持 iframe 隔离）。  
4. 《雲心文集》整书 PDF 行为与改前一致。

## 明确不做

- 服务端预生成 PDF。  
- 旅行卷「全部原图」进 PDF。  
- 本次修改《雲心文集》整书或文章页单篇 PDF（除非后续单独开项）。
