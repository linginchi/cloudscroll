# 雲箋文舍網站重設計任務書

日期：2026-07-04
角色定位：總設計師方案，用於交接 DeepSeek 先規劃、再執行。

## 一、項目定位

本網站不是一般文章網站，而是一位 88 歲中國語文老師、傳統文人、旅行書寫者的個人文集。網站應呈現為一本可慢慢翻閱的典雅旅行書，核心氣質是：

- 文人書房
- 紙本書卷
- 山川大海
- 雲海遠行
- 晚年回望
- 師者風範

網站主身份建議保持：

- 中文：雲箋文舍
- 英文：Cloudscroll
- 書名：我的人生旅行
- 作者：林樺

整體設計不追求華麗炫技，而追求清楚、安靜、耐看、親切。讀者可能包含長者、作者親友、不熟悉手機和電腦操作的人，因此操作清晰度優先於視覺複雜度。

## 二、設計總方向

推薦方向：淡雅紙本書房。

網站結構應像一次進書房讀書的過程：

1. 進入雲舍。
2. 看見三卷書。
3. 選一本書。
4. 讀作者自序或目錄。
5. 進入文章。
6. 可清楚返回、前後閱讀、調整字體。

視覺語言：

- 宣紙米白作底。
- 淡墨遠山、雲海、海天線作意象。
- 朱砂印章作少量點睛。
- 深墨、松綠、靛青、朱砂、銅金作系列色。
- 保留宋體/明體的書卷感，但提升字距、行距和可讀性。

避免：

- 現代卡片牆感過重。
- 過多小字、小圖標、小入口。
- 需要精準點擊的操作。
- 視覺上過暗、過花、過度動畫。
- 把網站做成普通博客或相冊。

## 三、閱讀互動模式重設計

### 3.1 核心原則

長者友好閱讀應做到：

- 每個畫面只保留少量主要操作。
- 所有可點擊區域足夠大。
- 永遠知道自己在哪裡。
- 永遠知道怎樣回去。
- 閱讀時不被社交和統計功能打擾。
- 字體大小可以明顯調整。

### 3.2 推薦閱讀路徑

首頁 → 書架 → 卷首頁 → 作者自序 / 目錄 → 正文閱讀。

目前網站已有 `index.html`、`shelf.html`、`volume.html`、`reader.html`，建議沿用現有結構，不重建路由系統。

### 3.3 閱讀頁改造

閱讀頁應改為「安心閱讀」模式。

頂部只保留：

- 返回目錄
- 文章標題
- 字體/語言入口

底部固定大按鈕：

- 上一篇
- 回目錄
- 下一篇

現有的讚、分享、閱讀數：

- 不作首屏固定操作。
- 可移到文章末尾。
- 或收進「更多」區域。
- 分享功能可保留，但不可干擾閱讀主流程。

### 3.4 字體控制

新增明顯的 `Aa` 閱讀設定入口。

至少三檔：

- 標準字
- 大字
- 特大字

切換時同步調整：

- 正文字號
- 行距
- 段距
- 圖文間距

選擇應保存於本機，下次打開仍維持。

### 3.5 目錄改造

目錄不應過度密集。每篇文章建議為大行距條目：

- 序號
- 文章題名
- 一句短摘
- 圖片數或文章長短提示

每個條目整行可點擊，手機上觸控區要大。

### 3.6 圖片閱讀

文章有大量圖片，圖片體驗應提升為半相冊模式：

- 正文圖片仍嵌入文章。
- 點擊圖片可進入大圖查看。
- 大圖模式可左右切換。
- 下方顯示第幾張 / 共幾張。
- 退出方式要明顯，例如「返回文章」。

第一階段若時間有限，可先做點擊放大單張圖，不必立即完成完整相冊。

## 四、整體包裝設計

### 4.1 首頁

首頁應像一本書的扉頁，而不是普通 landing page。

保留山水動畫基礎，但加強書卷感：

- 以「人生本是一場沒有歸期的遠行」作精神主句。
- 網站名「雲箋文舍」清楚可見。
- 主按鈕改為「進入雲舍書房」或「進入書架」。
- 避免讓整頁任何位置都像可點擊，主操作應明確。

### 4.2 書架

書架應像「案頭三卷」，不是現代商品卡片。

設計要求：

- 三本書為主角。
- 手機垂直排列，桌面橫向陳列。
- 背景為淡宣紙或淡木案頭感。
- 每本書有書脊、紙邊、陰影和厚度。
- 書架上方可寫「雲箋文舍」。
- 下方可寫「林樺先生旅行文集」。
- 加一個醒目的「先讀作者自序」入口。

### 4.3 卷首頁

每本書進入後不應立刻落入密集目錄，而應有卷首頁：

- 卷名
- 英文副題
- 作者名
- 一句卷意
- 開始閱讀
- 查看目錄

目前 `volume.html` 已有封面、自序、目錄三段，可沿用並優化。

### 4.4 作者自序

《自序》是全站精神核心，應提升權重。

可在以下位置出現：

- 書架入口：「先讀作者自序」
- 第一卷卷首頁下方
- 目錄第一項

自序中的關鍵句可作網站文案：

- 「人生本是一場沒有歸期的遠行」
- 「人生的精彩就在旅行」
- 「不是為了抵達目的地，而是為了享受旅途中的種種樂趣」

注意：不要重寫作者文字。只可選取短句作導讀。

## 五、三本書封面重設計

目前三本封面偏 placeholder，應重做為系列封面。

整體要求：

- 三本為同一套文集。
- 版式一致，色彩和意象各有區分。
- 文字少而清楚。
- 書名、輯名、作者最重要。
- 使用淡雅山水/雲海/海天意象，不要照片拼貼。
- 可用 CSS/Canvas/SVG 生成，也可用靜態圖片資產。

通用版式：

```text
我的人生旅行
第一輯

向世界出發

林樺 著
```

底部可有小朱印：「雲箋」。

### 5.1 第一輯《向世界出發》

- 主色：靛青、淡金、雲白。
- 意象：海天、遠帆、雲線、遠行。
- 氣質：開闊、出發、看世界。

### 5.2 第二輯《神州大地之行》

- 主色：朱砂深紅、暖金、宣紙白。
- 意象：山河、古城、長城遠影、江流。
- 氣質：厚重、家國、山河記憶。

### 5.3 第三輯《中外覽勝錄》

- 主色：松綠、銅金、淡墨。
- 意象：雲海、山海交會、晚晴遠遊。
- 氣質：從容、豁達、晚年漫遊。

## 六、DeepSeek 執行邊界

DeepSeek 應先提交規劃，不直接編碼。

第一輪不做：

- 不改文章內容。
- 不重寫自序。
- 不重做資料提取流程。
- 不引入大型前端框架。
- 不改部署架構。
- 不做後台管理。

第一輪可做：

- 改 HTML/CSS/Vanilla JS 呈現層。
- 改書架、封面、卷首頁、閱讀器互動。
- 新增長者閱讀設定。
- 新增圖片放大查看。
- 優化手機與桌面響應式。

## 七、建議實施順序

DeepSeek 的規劃應分四階段。

### 第一階段：現狀盤點

- 確認 `src/` 與 `dist/` 的構建關係。
- 確認封面由何處生成。
- 確認 `book/data.json` 的來源。
- 確認 `reader.js` 如何載入文章和圖片。
- 確認手機和桌面當前截圖。

交付：一份簡短技術改造計劃。

### 第二階段：視覺系統與書架封面

- 建立新的色彩變量。
- 重做書架。
- 重做三本封面。
- 優化首頁扉頁。

交付：首頁、書架、三卷封面截圖。

### 第三階段：閱讀互動

- 改閱讀頁頂部與底部操作。
- 新增上一篇/下一篇。
- 新增 `Aa` 字體設定。
- 調整目錄為長者友好大條目。

交付：手機與桌面閱讀截圖，並驗證可返回目錄。

### 第四階段：圖片與驗證

- 新增圖片點擊放大。
- 驗證大圖退出。
- 驗證 56 篇文章基本可打開。
- 驗證手機寬度下文字不重疊。

交付：驗證清單與截圖。

## 八、驗收標準

設計驗收：

- 一眼看出這是一套中國風文人旅行書。
- 三本書封面有系列感，也能分辨各卷氣質。
- 書架不再像普通卡片列表。
- 自序的精神被清楚呈現。

互動驗收：

- 長者可在 3 秒內看懂下一步按哪裡。
- 返回目錄、上一篇、下一篇清楚可用。
- 字體大小可調且保存。
- 手機上不需要精準點擊。
- 閱讀時沒有多餘干擾。

技術驗收：

- `npm run build` 可通過。
- 主要頁面手機與桌面截圖無重疊。
- 書架、卷首頁、閱讀頁可正常導航。
- 不破壞現有文章資料與圖片資產。

## 九、總設計師推薦結論

採用「淡雅紙本書房」方案。這個方案最符合作者年齡、教師身份、傳統文人氣質和旅行書寫主題，也最適合不熟悉手機和電腦的讀者。

設計重心不是增加功能，而是讓讀者安心：知道自己在書中、知道下一步、知道如何回去，並能舒服地慢慢讀。
